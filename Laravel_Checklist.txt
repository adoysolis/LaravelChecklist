DELETE FILE/FOLDER — POWERSHELL SYNTAX
--------------------------------------
IMPORTANT:
Do NOT use CMD syntax such as:

    rmdir /s /q vendor

inside PowerShell.

PowerShell syntax:

Delete a file:

    Remove-Item .\example.txt

Delete folder recursively:

    Remove-Item .\foldername -Recurse

Force deletion:

    Remove-Item .\foldername -Recurse -Force

Example:

    Remove-Item .\vendor -Recurse -Force

WARNING:
Do NOT delete vendor during an offline assessment unless you have a safe
way to restore dependencies.


COPY / MOVE / RENAME
--------------------
Copy file:

    Copy-Item source.txt destination.txt

Copy folder:

    Copy-Item .\source .\backup -Recurse

Move:

    Move-Item old.txt .\folder\

Rename:

    Rename-Item old.txt new.txt

============================================================
COMPOSER COMMANDS
============================================================

Check version:

    composer --version

Create Laravel project:

    composer create-project laravel/laravel project_name

Install packages from existing composer.lock:

    composer install

IMPORTANT DIFFERENCE:

    composer install

Uses the versions recorded in composer.lock. Usually the safer command.

    composer update

Looks for newer allowed package versions and changes composer.lock.
Avoid doing this casually during an assessment.

Regenerate Composer autoload files:

    composer dump-autoload

Useful when classes/files appear not to be recognized.

IMPORTANT:
composer install/update may require internet if packages are not cached.

CREATE MODEL
------------
Syntax:

    php artisan make:model ModelName

Example:

    php artisan make:model Product

Model + migration:

    php artisan make:model Product -m

Very useful shortcut:

    php artisan make:model Product -mcr

Depending on Laravel version/options, this can generate multiple related files.
For an assessment, using explicit commands is often easier to remember.


CREATE CONTROLLER
-----------------
Basic:

    php artisan make:controller ProductController

API controller:

    php artisan make:controller ProductController --api

Resource controller:

    php artisan make:controller ProductController --resource


CREATE MIGRATION
----------------
Syntax:

    php artisan make:migration migration_name

Example:

    php artisan make:migration create_products_table

Run migrations:

    php artisan migrate

See migration status:

    php artisan migrate:status

Rollback latest batch:

    php artisan migrate:rollback

Drop all tables and rerun migrations:

    php artisan migrate:fresh

WARNING:
migrate:fresh DELETES existing database tables/data.


CREATE FORM REQUEST / VALIDATION CLASS
--------------------------------------
    php artisan make:request StoreProductRequest

Example validation can also be placed directly in a controller:

    $validated = $request->validate([
        'name' => 'required|string|max:255',
        'price' => 'required|numeric|min:0',
        'stock' => 'required|integer|min:0',
    ]);

============================================================
LARAVEL API ROUTE SYNTAX
============================================================

routes/api.php:

Import controller:

    use App\Http\Controllers\ProductController;

One GET route:

    Route::get('/products', [ProductController::class, 'index']);

POST:

    Route::post('/products', [ProductController::class, 'store']);

GET one:

    Route::get('/products/{product}', [ProductController::class, 'show']);

PUT:

    Route::put('/products/{product}', [ProductController::class, 'update']);

DELETE:

    Route::delete('/products/{product}', [ProductController::class, 'destroy']);

Shortcut for REST API CRUD:

    Route::apiResource('products', ProductController::class);

This typically creates:
    GET       /api/products
    POST      /api/products
    GET       /api/products/{product}
    PUT/PATCH /api/products/{product}
    DELETE    /api/products/{product}


============================================================
CONTROLLER CRUD PATTERN
============================================================

Typical imports:

    use App\Models\Product;
    use Illuminate\Http\Request;

INDEX — READ ALL:

    public function index()
    {
        return Product::all();
    }

STORE — CREATE:

    public function store(Request $request)
    {
        $validated = $request->validate([
            'name' => 'required|string|max:255',
            'price' => 'required|numeric',
            'stock' => 'required|integer',
        ]);

        $product = Product::create($validated);

        return response()->json($product, 201);
    }

SHOW — READ ONE:

    public function show(Product $product)
    {
        return $product;
    }

UPDATE:

    public function update(Request $request, Product $product)
    {
        $validated = $request->validate([
            'name' => 'required|string|max:255',
            'price' => 'required|numeric',
            'stock' => 'required|integer',
        ]);

        $product->update($validated);

        return response()->json($product);
    }

DESTROY — DELETE:

    public function destroy(Product $product)
    {
        $product->delete();

        return response()->json(null, 204);
    }

COMMON HTTP STATUS CODES
========================
200 OK             = Request successful
201 Created        = New record created
204 No Content     = Successful, no response body (often DELETE)
400 Bad Request    = Bad request
401 Unauthorized   = Authentication required/failed
403 Forbidden      = Not allowed
404 Not Found      = Route/resource not found
405 Method Not Allowed = Wrong HTTP method
422 Unprocessable Content = Validation failed
500 Internal Server Error = Server-side/Laravel/PHP error

============================================================
COMMON ERRORS — QUICK CHECKS
============================================================

1) "Class ... does not exist"
--------------------------------
Check namespace/import spelling.

Correct example:

    use App\Http\Controllers\ProductController;

NOT:

    use app\Http\Controllers\ProductController;

PHP/Laravel convention uses capital "App".

Try:

    composer dump-autoload
    php artisan optimize:clear


2) "syntax error, unexpected token public"
-------------------------------------------
Usually check:
- Missing }
- Extra }
- Missing ;
- A method accidentally placed inside another method

In a controller, methods should look like:

    class ProductController extends Controller
    {
        public function index()
        {
            ...
        }

        public function store(Request $request)
        {
            ...
        }
    }


3) 404 Not Found
----------------
Run:

    php artisan route:list

Verify:
- Correct URL
- /api prefix
- Correct route spelling


4) 405 Method Not Allowed
-------------------------
Correct endpoint but wrong method.

Example:
Route expects POST but Postman is using GET.


5) 422 Validation Error
-----------------------
Laravel received the request, but submitted data failed validation.
Check Postman JSON field names and required values.


6) 500 Error
------------
Look at:
- Terminal running php artisan serve
- storage/logs/laravel.log

PowerShell last lines:

    Get-Content .\storage\logs\laravel.log -Tail 50


7) Database connection error
----------------------------
Check:
- MySQL running in XAMPP
- Database exists
- .env DB_DATABASE
- Username/password
- Port

Then:

    php artisan config:clear


8) "getaddrinfo ENOTFOUND api" in Postman
-----------------------------------------
Do NOT enter only something like:

    api/products

Use the complete local URL:

    http://127.0.0.1:8000/api/products
